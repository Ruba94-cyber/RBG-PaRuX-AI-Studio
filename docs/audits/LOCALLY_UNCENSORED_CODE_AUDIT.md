# Locally Uncensored code audit (v3.0.6, clean-room)

> Generated from the structured output of nine read-only domain audits (see `docs/audits/parts/*.md` for the narrative evidence).
> Evidence levels: **static** = code read, **unit_tests** = named automated tests exist (not necessarily executed by the auditor), **e2e_real** = a recorded real run, **none** = no evidence.
> The audit was static: nothing was built, run or fetched by the auditors. Statements about Locally Uncensored (LU) describe observable behaviour in the auditors' own words; no LU code is reproduced (LU is AGPL-3.0, PaRuX is MIT).

Subject: Locally Uncensored v3.0.6 (the version installed on the reference PC; upstream has since tagged v3.0.7). Licence: GNU AGPL-3.0. The source was read to understand observable behaviour only; this document contains behavioural descriptions and file references, never code.

## Model discovery, catalog and capabilities

**Real strengths found in LU**

- Shard-aware GGUF selection: parts are grouped, ordered and sized before download (src/api/discover.ts:1676-1739; engine.rs scan tests 9004 and 9023).
- Projector pairing carried through download and import, with an explicit text-only note (src/api/model-bundles.ts:42-59; engine.rs:4477-4479).
- Three-state fit verdict with unknown-is-not-zero and a slow-load hint (src/lib/vram-fit.ts:37-224; src/lib/hardware.ts:42-50).
- Read-only scan of Ollama and LM Studio stores with already-imported flags and same-volume hard-link import (engine.rs:4350-4506).
- Uncensored catalogue kept in its own tab with Mainstream as the default (src/components/models/DiscoverModels.tsx:232, 360).
- Installed-file identity by exact byte count, so a same-name mirror is not counted as installed (src/api/model-bundles.ts:39-41).

## Download manager

**Real strengths found in LU**

- Stall-based timeouts (connect and per-read) instead of a whole-transfer deadline (download.rs:1373-1381, 1491)
- Free-space checks before the first byte, with fixed reserves and in-flight bytes counted for bundles (download.rs:1179, 1210, 1959-2017)
- Existing files accepted only on an exact server-stated size, with no percentage threshold (download.rs:1108-1119)
- Host-gated credentials for the hub and CivitAI, with redirect checks and tested host rules (download.rs:1257-1381)
- Separate pause, cancel and clear semantics, with the partial kept unless the user cancels (download.rs:1738-1939)
- Global bandwidth limit shared by all model transfers (download.rs:1009-1056)
- Startup scan for orphan partials with resume and discard (download.rs:2090-2183)
- Gated-repository and dead-address messages that name the next step and offer Retry only where it can help (download.rs:1145-1174, 1300-1337)
