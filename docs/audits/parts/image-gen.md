## 2. Method and evidence rules

- Static reading only. Nothing was built, tested or run in PaRuX. No LU script or binary was executed, no network was used, and LU user data was not read. Discovery used symbol queries and narrow search; reads were limited to decisive ranges. Line numbers are 1-based.
- Evidence levels: `static` = code read; `unit_tests` = test class and fact names exist (counts are attribute counts, not executions); `e2e_real` = a real run recorded in docs or the plan. Recorded run artifacts are not retained in this worktree (`.ai/artifacts/` holds only `.gitkeep`).
- Provenance caveat: the plan cites commits 158719b (Create edit routing), 799676c (Wan clip continuity) and 9a93076 (CUDA bundles) as verified. None is an ancestor of HEAD; they sit on other branches. HEAD contains the edit-mode separation by static reading (section 4, row 14).
- LU `verified` flags are the authors' declarations (`src/api/model-bundles.ts` 905-907). They were not re-run.

## 6. Risks

- Silent wrong-VAE selection in LU (static reading, not executed): the Z-Image and FLUX.1 VAE searches fall back to a bare "ae" substring (comfyui.ts 1669-1683). VAE file names such as flux2-vae or wan2.2_vae also contain "ae". With ae.safetensors absent, a different family's VAE could be chosen without an error.
- Silent wrong-family override in PaRuX: any diffusion_models file can be assigned (row 7). The failure appears inside ComfyUI, not in PaRuX.
- Shared file names: LU shares by name only. A file replaced under a shared name (ae.safetensors, flux2-vae.safetensors, qwen_3_4b.safetensors) changes every family that uses it. Neither app verifies identity beyond size and, where present, sha256.
- Community content: LU lists community UNETs and encoders with unverified status; PaRuX's FLUX.2 base entry points to a repository outside the Comfy-Org namespace, while LU takes the same file name from Comfy-Org. Publisher checks, labels and product policy are needed before any default-on download.
- Licence differences apply per file: the Qwen Research License (ModelHubView.cs 3196), the Krea 2 community licence (docs/image-model-decisions.md 32-35) and Apache-2.0 for FLUX.2 Klein (docs 42). Each companion needs its own licence evidence, as the consent flow already does for single files.
- Size and completeness: companion sets run to roughly 16 to 29 GB. LU's partial-file check uses sizes rounded to GiB (comfyui.ts 958-973), so it is approximate.
- Evidence provenance: cited live runs (158719b, 799676c, 9a93076) are not in HEAD; BIC-13 remains PARTIAL (plan 764-771).
- Status mismatch: DescribeMediaRole can report a file the graph does not load (row 7).
- Port reuse: the race starts ComfyUI on fixed port 8188 (ManagedComfyImageRaceEngine.cs 140-142). A leftover process from another path could hold the port. Not verified.
